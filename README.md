# 여행 관리 프로그램

Java 17 이상이 필요합니다. Maven은 포함된 Wrapper가 준비합니다.
최초 실행에는 Maven과 JDBC 드라이버 등을 내려받을 인터넷 연결이 필요합니다.

## 실행

macOS / Linux:

```sh
./run.sh
```

Windows:

```bat
mvnw.cmd -q compile exec:java
```

IntelliJ에서는 `pom.xml`을 Maven 프로젝트로 불러온 뒤
`kr.ac.konkuk.Main`을 실행해도 됩니다.

기본 실행은 여행 상세 Swing 미리보기를 엽니다. 변경사항은 저장되지 않습니다.
실제 여행을 관리하려면 Windows에서 `mvnw.cmd -q compile exec:java "-Dexec.args=--console"`을 실행하세요.
macOS / Linux에서는 `./run.sh -Dexec.args=--console`을, IntelliJ에서는 `kr.ac.konkuk.MainConsole`을 실행할 수 있습니다.

## 사용 방법

1. 시작 메뉴에서 회원가입합니다. 이름, 아이디, 비밀번호를 입력합니다.
2. 아이디와 비밀번호로 로그인합니다.
3. 새 여행 등록에서 도시를 검색하고 도시 번호와 여행 기간을 입력합니다.
4. 여행 상세에서 할 일, 항공, 숙박, 일정, 여행 유의사항을 관리합니다. `6`을 선택하면 할 일, 항공권, 숙박, 일정 관리 창이 열리며, 창을 닫으면 변경사항이 저장됩니다.
5. 여행 관리 메뉴의 `0`은 로그아웃, 시작 메뉴의 `0`은 프로그램 종료입니다.

비밀번호는 입력한 문자열의 Java `String.hashCode()` 값을 저장하고 비교합니다.
비밀번호 앞뒤의 공백도 입력한 그대로 반영합니다.
날짜 형식은 `YYYY-MM-DD`, 항공 시각은 `YYYY-MM-DD HH:mm`입니다.
항공 시각을 입력하면 `+09:00` 같은 UTC 시차도 입력합니다.
상세 항목의 날짜는 미정으로 둘 수 있습니다. Swing 수정 창에는 기존 값이 채워져 있으며,
날짜를 지우면 미정으로 저장합니다. 콘솔 수정에서는 빈칸으로 기존 날짜를 유지하고 `없음`으로 지웁니다.

## 데이터 저장

`src/data.db`에 회원과 사용자별 여행, 할 일, 항공, 숙박, 일정을 저장합니다.
새 여행 등록 시, 세부 관리 메뉴에서 상세 메뉴로 돌아올 때,
로그아웃하거나 입력이 종료될 때 자동 저장합니다.
재실행 후 같은 계정으로 로그인하면 저장된 정보를 불러옵니다.
기존 국가·도시 데이터는 그대로 사용하며 필요한 저장 테이블은 시작 시 추가합니다.

다른 DB 파일을 사용하려면 다음과 같이 기존 파일의 경로를 지정합니다.

```sh
./run.sh -Dtravel.db.path=/absolute/path/data.db
```

## 테스트

```sh
./mvnw test
```

테스트는 임시 DB를 사용하므로 실제 `src/data.db`의 회원·여행 데이터에 영향을 주지 않습니다.
